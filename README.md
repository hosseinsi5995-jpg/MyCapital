# MyCapital — مدیریت سرمایه آنلاین

نسخه آغازین یک داشبورد فارسی و واکنش‌گرا برای مدیریت سرمایه، حساب‌ها، تراکنش‌ها و رصد بازار.

## امکانات موجود در این نسخه
- رابط کاربری تیره با رنگ سبز نئونی
- ثبت‌نام و ورود ایمیل/رمز با Supabase Auth
- تفکیک داده‌ها بر اساس شناسه کاربر با Row Level Security
- ثبت حساب و موجودی اولیه
- ثبت واریز/درآمد و برداشت/هزینه
- خلاصه دارایی‌ها و نمودار ترکیب حساب‌ها
- نمایش دلار آزاد، طلای ۱۸ عیار و بیت‌کوین از منبع عمومی Iran Market Data
- دفتر ثبت دستی معاملات فیوچرز ارز دیجیتال: نماد، Long/Short، قیمت ورود/خروج، Stop Loss، Take Profit، حجم، اهرم و زمان ورود/خروج
- تفکیک معاملات باز و بسته و محاسبه سود/زیان تحقق‌یافته از روی قیمت‌های واردشده
- واکنش‌گرا برای موبایل و دسکتاپ

## ۱) ساخت پروژه Supabase
1. وارد https://supabase.com شو و یک پروژه جدید بساز.
2. از بخش **Project Settings → API** مقدار Project URL و `anon` / publishable key را بردار.
3. فایل `supabase.sql` را در **SQL Editor** اجرا کن.
4. در فایل `app.js` این دو مقدار را جایگزین کن:
   - `YOUR_SUPABASE_PROJECT_URL`
   - `YOUR_SUPABASE_ANON_KEY`
5. کلید `service_role` را هرگز در فایل‌های سایت قرار نده. فقط کلید عمومی anon/publishable مجاز است و امنیت داده‌ها با RLS اعمال می‌شود.

## ۲) ساخت حساب‌ها
- خودت از فرم سایت ثبت‌نام کن.
- معلم هم جداگانه با ایمیل خودش ثبت‌نام کند.
- هر کاربر فقط ردیف‌هایی را می‌بیند که `user_id` آن‌ها شناسه خودش است.
- اگر تأیید ایمیل در Supabase روشن باشد، هر نفر باید ایمیل خود را تأیید کند.

## ۳) انتشار روی GitHub Pages
1. در GitHub یک repository جدید با نام دلخواه مثل `mycapital` بساز.
2. تمام فایل‌های این پوشه را در ریشه repository بارگذاری کن.
3. برو به **Settings → Pages**.
4. در **Build and deployment** گزینه **Deploy from a branch** را انتخاب کن.
5. Branch را روی `main` و پوشه را روی `/ (root)` قرار بده و Save کن.
6. پس از انتشار، آدرس سایت در همان صفحه نمایش داده می‌شود.

## ۴) اجرای آزمایشی روی کامپیوتر
می‌توانی `index.html` را باز کنی؛ بهتر است برای تست محلی از افزونه Live Server در VS Code استفاده کنی. تا قبل از تنظیم Supabase، ورود و ذخیره آنلاین فعال نمی‌شود.

## نکات مهم
- GitHub Pages فقط فایل‌های فرانت‌اند را میزبانی می‌کند؛ دیتابیس و احراز هویت روی Supabase است.
- GitHub Pages و Supabase در پلن رایگان محدودیت و شرایط استفاده خودشان را دارند؛ «همیشه آنلاین» به معنی تضمین ۱۰۰٪ بدون قطعی نیست.
- منبع قیمت بازار: https://github.com/iran-market/iran-market.github.io
- قیمت‌های منبع عمومی با تأخیر انتشار تقریبی ۳۰ دقیقه ارائه می‌شوند و ممکن است گاهی قدیمی یا در دسترس نباشند. این قیمت‌ها را مبنای قطعی معامله قرار نده.
- برای فعال‌شدن دفتر معاملات، نسخه جدید `supabase.sql` را کامل در Supabase → SQL Editor اجرا کن. اگر جدول‌های قبلی از قبل وجود دارند، اجرای دوباره این فایل جدول‌های موجود را حذف نمی‌کند و جدول `trades` را اضافه می‌کند.
- دفتر معاملات فعلاً ثبت دستی است و قیمت زنده، اتصال به صرافی، ثبت سفارش واقعی، کارمزد و ویرایش/حذف معامله ندارد.
- فرمول سود/زیان ناخالص قرارداد خطی USDT-M است: برای Long برابر (خروج − ورود) × حجم و برای Short برابر (ورود − خروج) × حجم. حجم باید تعداد کوین باشد، نه ارزش دلاری پوزیشن. اهرم در این نسخه ثبت و نمایش داده می‌شود، اما سود/زیان دلاری را چند برابر نمی‌کند؛ اهرم روی مارجین موردنیاز و درصد بازده مارجین اثر دارد.
- انتقال بین حساب‌ها، ویرایش/حذف رکوردها، PIN و گزارش‌های پیشرفته هنوز در این نسخه پیاده‌سازی نشده‌اند.
